# Foundation UI Lab

Product-neutral, interactive examples that consume only Foundation public exports. The Lab is documentation and migration evidence; it is never the implementation source for a public Pattern.

The first migrated surface is the experimental Collection Pattern. Legacy platform previews for Dashboard, Settings, Feedback and BackToTop remain review evidence until each capability passes its own Interface, tarball and real-consumer promotion gate.

Run from the Foundation root:

```sh
pnpm --filter @yueli/ui-lab dev
```
