# 授权角色标签

后台授权用户使用 `AuthorizationGrantBadge`（`@yueli/ui/admin`），产品传入角色显示名 `role` 和原始授权来源 `source`。

- 标签只显示角色名，统一使用 Nuxt UI 中性软背景小标签；不把角色和授权来源拼接成文本框。
- 来源在悬停及键盘聚焦提示中显示中文，读屏名称同时包含角色和来源。
- `initial_claim` 为“首次管理员认领”，`bootstrap` 为“系统初始化”；两者不能混用。
- 同时覆盖申请批准、邀请加入、直接授予、自动授权、用户组授权、服务配置、导入同步、管理员恢复。
- 空来源显示“来源未记录”，未知来源显示“其他授权方式”，不得直接显示内部枚举值。
- 角色名称属于产品角色目录，来源映射和标签样式属于共享组件。撤销权限、确认步骤和提交逻辑仍由产品管理。
