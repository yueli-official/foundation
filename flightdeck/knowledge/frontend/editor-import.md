# 编辑器图片与文档导入

所有富文本编辑器复用 ContentEditor 的图片和导入入口。产品只提供 imageUploader(File)，由既有 Asset 图片处理器负责图像处理和正式上传，不能在编辑器内复制后端/对象 Key/Finalize 协议。

图片按钮打开共享上传模块，支持多选、拖拽、剪贴板与逐项处理状态；正文直接粘贴、拖拽也走同一上传队列，不因上一项正在上传而静默忽略下一项。异步插入位置使用当前编辑器的 selection bookmark 随事务映射，避免上传期间编辑导致插错位置。

文档导入插入当前正文，不默认覆盖。支持 Markdown、HTML、Word docx、保留图片目录的 ZIP 与富文本粘贴。先解析和清洗，再预检全部图片引用，完成资源处理后一次插入。不能静默丢图、保留本地 file/blob/Base64 地址或写入半篇内容；错误留在对话框中，用户可补充文件重试。

本地图片优先按相对路径精确匹配；浏览器只给文件名时，只有唯一匹配才可接受。压缩包限制单文件、总展开体积与数量。远程图片读取失败或不允许跨域时提示下载后补充，不能为了导入功能临时增加无边界的服务器抓取代理。

验收必须包含非空原文、多图、剪贴板、相对路径 ZIP、Word 内嵌图、HTML 清洗、缺图/上传失败、保存重载和手机尺寸。类型检查与静态资源上线不等于真实管理员上传验收。

## URL 图片失败不阻断正文

导入 Markdown 或粘贴富文本时，HTTP(S) 图片先尝试读取和上传。单张外链失败时，在原位置插入“图片未导入”及原图链接，继续其他图片和正文；占位内容必须能随 Markdown 保存与回读。剪贴板真实图片文件或 Base64 仍走图片上传。缺少本地配图仍提示补充文件。不得用损坏 img 或保留外链 img 冒充成功上传。
