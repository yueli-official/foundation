# 内容编辑工作台

2026-09-08 用户指定 Blog 为编辑器模板、Docs 为列表操作模板。延续紧凑、干净、少用色的后台风格。

## 共享结构

- 正文编辑页使用 `@yueli/ui/admin` 的 `EditorCommandBar`，外层后台开启 immersive 布局以移除普通页面的面包屑与边距；用户主动进入沉浸模式时切换到纯写作区域。
- 命令顺序：返回与标题；沉浸、公开页或明确标注的草稿预览、设置、发布状态、保存。使用 title/status/preview/lifecycle/actions 插槽，不在共享组件调用产品 API。
- 窄屏分成标题行与操作行，防止按钮把标题挤没；桌面同一行。图标按钮 32px，保存与发布使用紧凑高度。保持图标可访问名称。
- 设置复用 `EditorInspector`，1280px 起停靠；正文给停靠面板留空间，小屏抽屉遮罩。产品自己的交付、版本、分类等表单继续由产品维护。

## 编辑界面构建规则

编辑页由共享命令栏、正文工作区、默认收起的设置面板组成。接入顶栏只完成了一部分，必须同时整理正文和元信息的位置。

- 标题在命令栏编辑；正文工作区直接进入 ContentEditor，不在编辑器上方重复标题或排列 slug、摘要等表单。
- 路径标识、简短说明/摘要、封面、分类标签、SEO、日期、排序与产品专有元信息统一进入 EditorInspector。字段校验与保存合同仍归产品，移入面板后保留可访问标签和错误关联。
- 设置默认收起，桌面停靠、小屏抽屉；修改设置后保存整份当前内容，不创建另一份表单状态。
- 发布/已发布入口固定在设置与保存之间。新建内容也能直接发布；加载时保留入口并禁用，加载失败明确反馈，不能静默留下可操作的空编辑器。
- 已发布菜单提供下架；下架后恢复发布入口。公开页按钮只在确有公开页时出现。权限不足按产品权限显示，不以是否加载到数据代替权限判断。
- 沉浸、设置、发布、保存必须验证实际交互，不能只凭用了共享组件宣称完整适配。

验收至少覆盖新建与已有内容、默认正文无元信息、设置中可编辑并保存、窄屏布局、发布后匿名可读与下架后原链接不可读；线上部署需确认候选制品包含当前代码。

## 关系字段按需选择

父文档等可能增长的关系字段使用服务端搜索式选择器：打开时读取最多 20 条候选，输入关键词防抖后重新查询，前端不拉全量再过滤。当前选中项的名称单独保留，不能因为不在首批结果中就显示成 ID 或丢失。请求失败可原地重试，旧搜索响应不得覆盖新结果。

当前文档按 ID 或精确语义路径独立定位、加载，进入编辑器和保存跳转都不依赖整集目录。候选在服务端排除当前文档及其子树，保存时仍校验循环关系及集合/语言/版本一致性。无父文档作为独立固定选项，不计入 20 条候选。

## 完全沉浸模式

沉浸模式隐藏侧栏、面包屑及整条编辑命令栏（标题、发布和保存也隐藏），设置面板同时关闭。正文工作区从视口顶部开始占满宽高，移除外层卡片留白；编辑器工具栏保留，右侧放置带可访问名称的退出按钮。退出后恢复原编辑界面和未保存内容。验收需断言命令栏确实消失、工作区从 y=0 开始，而不只是检查一个 immersive 属性。

## 发布含义

用户明确要求“不公开”就是下架：访客通过原链接也不能读取。不得增加“仅链接可见”或以换文案代替服务端限制。内部草稿、归档、商品状态无需为了 UI 统一强行改数据库。

发布必须先保存当前正文，保存失败不能发布旧内容。只有服务端成功后才能显示已发布；UI 不做乐观状态切换。独立保存不应意外发布或改变可见性。公开页按钮访问真实公开 URL；草稿预览仅能使用已有鉴权边界并明确命名。

## 列表编辑

公开页（仅已发布）→快速编辑→完整编辑→产品特有操作。Docs 保留添加子文档，产品保留自己的权限控制。快速编辑读取完整对象与修订号，提交时保留未编辑字段。

`CollectionPanel` 发出 `editItem`，消费者导航到完整编辑页。共享 `isCollectionEditGesture` 排除选择框、链接、按钮、输入框及可编辑区域；不让双击编辑抢占这些操作。

Nuxt UI `UTable` 的 select 回调会先 preventDefault，并将行标为 role=button，不能把它当作原始双击事件直接传入该判断。Docs 用 table 根 dblclick 加行内稳定文档 ID 解析目标，避免依赖可变行序号。

## 已验证与发布边界

Blog、Docs、WWW、Resource、Shop 接入。每站通过 390/768/1024/1440px 与浅/深色 Playwright 检查；各站真实发布后匿名原链接 200，下架 404，再发布恢复 200。WWW 额外验证保存请求失败不显示已发布、快速编辑保留正文。Docs 验证新建保存正文后直接发布，并在语义路径跳转前刷新文档树。

共享事件 16 项相关测试及类型检查通过；五站类型检查与构建通过。在线站点使用独立固定依赖候选制品，基础服务和数据库不需要迁移。具体部署结果归各产品 Work，不能把本地浏览器通过写成线上管理员交互通过。
