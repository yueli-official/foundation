# 个人令牌与消费站点权限

Identity 管理凭证、期限、撤销和明确授权范围，消费站点管理角色及资源授权。实际请求必须同时通过 Token 能力限制和当前业务权限决策。禁止把创建时角色快照当作永久权利；新增角色能力不扩张已有 Token。

可委托目录是消费者明确声明的子集，由可信注册元数据定位。创建界面只展示当前用户可申请能力，提交后端重新查询。目录用于选择，不是资源授权结果；IncludeDescendants 只能用于发现能力，不能据此跳过业务 Decide。

共享 Foundation auth 提供 scope 编解码、在线验证、认证组合和目录查询。BFF 保留显式 PAT，验证失败不退回 Cookie。未审查路由默认拒绝，安全设置/Token 签发/权限治理不自动开放。

媒体服务通过可信消费者验证原 PAT 和当前业务权利，只接受返回的具体 Profile 限制，继续检查 client/namespace/profile 与资源所有者，不能兑换无限制服务 Token。

本地真实角色撤销、Token 撤销、文章与上传闭环已验证。当前单进程授权投影不保证多副本即时失效，已授权进行中的操作不会被追溯取消。

配置、发布边界及证据见 [接入说明](../../work/2026-09-09-personal-token-authorization/integration.md) 和 [验收记录](../../work/2026-09-09-personal-token-authorization/acceptance.md)。

用户要求随时复制时，采用独立派生密钥的认证加密保存原文，AAD 绑定 owner 与 Token hash；仍使用摘要验证。原文只在本人会话显式读取接口返回，禁止缓存及原文日志，集合 DTO 不携带原文/密文。旧摘要无法逆向恢复，不为兼容自动重置凭据。
